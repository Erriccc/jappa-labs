# Provider directory: US to Nigeria

This is a neutral list of the shipper and forwarder types found in the research, **as of 28 Nov 2026**:
- **No paid placement.** A listing is not an endorsement.
- **Order is alphabetical** within each type.
- **Prices are not here.** They are in [price-baseline.md](price-baseline.md).
- **"URL not recorded"** means the research named the provider but kept no link; find it with WebSearch.

**Providers can request a listing or a correction** by opening an issue at https://github.com/Erriccc/jappa-labs/issues. Please include a public pricing page. Listings stay neutral; there is no paid placement.
