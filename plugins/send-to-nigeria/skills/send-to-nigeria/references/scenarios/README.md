# City scenarios: US city x size class, to Nigeria

Each file is a local guide for one US origin. It has one section per size class from [size-classes.md](../size-classes.md). Every section ends with an **expected best route and why**, so the files double as test cases.

| Sender's city | File |
|---|---|
| Chicago (and northwest Indiana) | [chicago.md](chicago.md) |
| Washington DC, Baltimore, Northern Virginia | [dc-baltimore.md](dc-baltimore.md) |
| Houston and Texas | [houston-texas.md](houston-texas.md) |
| Atlanta and Georgia | [atlanta.md](atlanta.md) |

**How to use these files:**
- Read the file that matches the user's city, then the section that matches the size class.
- Re-check the live pages for the shortlisted routes before quoting ([recheck-live.md](../recheck-live.md)).
- **For a city not listed here**, follow [research-method.md](../research-method.md) and fill in [templates/scenario-template.md](../templates/scenario-template.md) live. Label every figure "found live on <date>, not yet reviewed".

Baseline **as of 28 Nov 2026**. This is not legal or customs advice.
