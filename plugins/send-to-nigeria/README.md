# send-to-nigeria

A Claude Code plugin that helps shoppers in Nigeria and senders in the US find the cheapest, safest way to get goods from the US to Nigeria. It compares the realistic routes for your item and returns two or three ranked options, each with sourced, dated figures, after re-checking providers' live pages.

This is general information, not legal, customs or tax advice. Confirm with the carrier, forwarder or Nigeria Customs Service before you ship.

## Skills

- **send-to-nigeria** runs on its own when you ask how to ship, send or buy something from the US to Nigeria, or what it will cost.
- **ship-quote**: run `/send-to-nigeria:ship-quote [item]` for a step-by-step quote, one short question at a time.

## Install

```
claude plugin marketplace add Erriccc/jappa-labs
claude plugin install send-to-nigeria@jappa-labs
```

Or inside Claude Code: `/plugin marketplace add Erriccc/jappa-labs`, then `/plugin install send-to-nigeria@jappa-labs`.

## The guide

Routes, size classes, duty, prohibited items and city guides are on the site, built from this plugin's files: [Send to Nigeria](https://erriccc.github.io/jappa-labs/send-to-nigeria.html).
